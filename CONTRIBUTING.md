Guía rápida para contribuir

Gracias por contribuir a este proyecto. Pautas mínimas:

- Trabaja en la rama main (acuerdo del equipo: 2 personas).
- Realiza cambios pequeños y atómicos con mensajes claros de commit.
- Ejecuta y prueba localmente antes de hacer push.
- Para cambios de UI, evita alterar la lógica de negocio o la capa de datos sin consenso.

Comandos útiles:

```powershell
git status
git add .
git commit -m "Mensaje claro"
git push origin main
```

Contacta con tu compañero/a si el cambio es mayor a 1 archivo o afecta la base de datos.
